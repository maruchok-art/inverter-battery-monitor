# 🔋 Inverter Battery Monitor

> Система моніторингу резервного живлення для багатоквартирного будинку (ОСББ)

Бот автоматично стежить за зарядом акумуляторів інвертора Deye і надсилає сповіщення мешканцям у Telegram. Від акумуляторів живляться ліфт, насоси холодної та гарячої води й опалення. Коли світло зникає — всі одразу знають, скільки заряду лишилось і чи можна користуватись ліфтом.

---

## ✨ Можливості

- 📡 Підключення до інвертора Deye через офіційний хмарний API
- 📲 Сповіщення в Telegram-канал, коли зникло світло і падає заряд
- 🌐 Веб-сторінка з поточним зарядом, станом мережі та часом останнього оновлення
- ⚠️ Сторінка попереджає, якщо дані давно не оновлювались (бот міг зупинитись)
- 📱 Встановлюється як додаток на телефон (PWA)
- ⚡ Запускається кожні 10 хвилин через cron-job.org + GitHub Actions

---

## 🚦 Рівні сповіщень

Сповіщення про заряд надсилаються лише коли зникла мережа (напруга нижче 180 В хоча б на одній фазі). Поки світло є, інвертор заряджає акумулятори і тривог немає.

| Рівень | Заряд  | Повідомлення                                                 |
| ------ | ------ | ------------------------------------------------------------ |
| 🟡     | 50–90% | Будинок працює від акумуляторів                              |
| 🟠     | 30–50% | Заряд акумуляторів обмежений                                 |
| 🔴     | 15–30% | Низький заряд акумуляторів                                   |
| 🔴🆘   | < 15%  | Критичний заряд акумуляторів — інвертор вимкнеться при 10%   |
| ⚠️     | —      | Втрачено зв'язок з інвертором                                |
| ✅     | —      | Зв'язок з інвертором відновлено, показано поточний заряд     |

Як працюють сповіщення:

- Кожне повідомлення надсилається **один раз** при переході на новий рівень, без повторів кожні 10 хвилин.
- Якщо Telegram тимчасово не прийняв повідомлення, бот пробує ще раз і, за потреби, повторює на наступному запуску — повідомлення не губляться.
- «Втрачено зв'язок» надсилається, якщо хмара Deye не відповіла **2 рази поспіль** (≈20 хв) — разові збої не лякають мешканців. Якщо Deye прямо повідомляє, що інвертор не на зв'язку, — одразу.
- Після повернення світла тривоги скидаються, лише коли мережа стабільна **2 запуски поспіль**. Тому, якщо світло «блимає», повідомлення не дублюються.

## 📊 Веб-сторінка

👉 **[Відкрити сторінку](https://maruchok-art.github.io/inverter-battery-monitor/dashboard.html)**

На сторінці:

- **заряд** акумуляторів у кільці (колір відповідає рівню);
- **стан**: ✅ мережа є / ⚡ мережа є, акумулятори заряджаються / 🟡🟠🔴 живлення від акумуляторів / 📡 зв'язок втрачено;
- **коли оновлено**: «Оновлено 3 хв тому» і точний час;
- ⚠️ **«Дані застарілі»**, якщо оновлень не було понад 30 хвилин.

Сторінка оновлюється сама кожні 10 хвилин, а також одразу, коли повертаєшся до неї з іншого застосунку. Кнопка оновлення не потрібна.

Встановити як додаток на телефон:

- 🤖 Android — Chrome → три крапки ⋮ → «Додати на головний екран»
- 🍎 iOS — Safari → кнопка «Поділитись» → «На початковий екран»

## 🏗 Як це працює

```
Інвертор Deye
      ↓ (Deye Cloud API)
  Python скрипт (main.py)
      ↓ (кожні 10 хв через cron-job.org + GitHub Actions)
  GitHub Gist (зберігання стану)
      ↓
  Telegram канал  +  Веб-сторінка
```

- Запуск — через cron-job.org: власний розклад GitHub ненадійний (спрацьовує лише кілька разів на добу), тому не використовується.
- Два запуски ніколи не працюють одночасно — другий чекає своєї черги.
- Якщо запуск завис, GitHub зупиняє його через 5 хвилин (звичайний запуск триває ~20 секунд).

## 🔒 Безпека

- Паролі й ключі зберігаються **тільки** в GitHub Secrets (див. крок 1). Ніколи не вписуйте їх прямо у файли репозиторію — репозиторій публічний, і навіть видалений файл лишається в історії змін.
- Файл стану в Gist може прочитати будь-хто (його читає веб-сторінка). Тому бот **не зберігає** там жодних ключів: ключ доступу до Deye він отримує заново на кожному запуску і ніде не записує.

## 🔧 Налаштування

### Крок 1 — GitHub Secrets

Додати в Settings → Secrets and variables → Actions:

```
TG_BOT_TOKEN            — токен Telegram бота (@BotFather)
TG_CHAT_ID              — ID Telegram каналу
SOLARMAN_APP_ID         — App ID з Deye Developer Portal
SOLARMAN_APP_SECRET     — App Secret з Deye Developer Portal
SOLARMAN_EMAIL          — email акаунту Deye
SOLARMAN_PASSWORD       — пароль акаунту Deye
DEVICE_SN               — серійний номер інвертора
GIST_ID                 — ID Gist зі станом (файл state.json)
PERSONAL_GITHUB_TOKEN   — особистий токен GitHub з правом gist
```

### Крок 2 — GitHub Gist

Створити новий gist на [gist.github.com](https://gist.github.com):

- Назва файлу: `state.json`
- Вміст:

```json
{"state": 0, "tg_state": 0}
```

Скопіювати ID з адреси gist і додати в secrets як `GIST_ID`.

### Крок 3 — GitHub токени

Потрібно два окремих токени (Settings → Developer settings → Personal access tokens):

| Токен                   | Права                                                         | Використання                        |
| ----------------------- | ------------------------------------------------------------- | ----------------------------------- |
| `cron-job token`        | Fine-grained, доступ лише до цього репозиторію: Contents — Read and write | Для cron-job.org — запуск бота      |
| `PERSONAL_GITHUB_TOKEN` | `gist`                                                        | Для скрипту — читання і запис стану |

Давайте токенам мінімум прав: якщо токен колись витече, він не відкриє доступ до всього акаунту.

### Крок 4 — cron-job.org

Налаштувати завдання для запуску кожні 10 хвилин:

- **URL:** `https://api.github.com/repos/maruchok-art/inverter-battery-monitor/dispatches`
- **Method:** POST
- **Headers:** `Authorization: Bearer CRON_JOB_TOKEN`, `Content-Type: application/json`
- **Body:** `{"event_type": "trigger"}`

Порада: увімкніть у cron-job.org сповіщення на пошту про невдалі запуски — так ви дізнаєтесь про проблему раніше за мешканців.
